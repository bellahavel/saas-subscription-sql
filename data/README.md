# Data

This project uses the ChartMogul sample invoice dataset. Raw CSVs are not committed to this repo.

Download and unzip the dataset here:
- https://chartmogul-samples.s3.eu-west-1.amazonaws.com/public/Sample_csv_files.zip

After unzipping, place the CSVs in this folder:
- `data/01_Customers.csv`
- `data/02_Contacts.csv`
- `data/03_Plans.csv`
- `data/04_Invoices.csv`
- `data/05_Invoice_line_items.csv`
- `data/06_Transactions.csv`
- `data/07_Subscription_events.csv`
